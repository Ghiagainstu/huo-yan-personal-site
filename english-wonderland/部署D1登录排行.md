# english-wonderland 登录 + 排行榜 部署手册（Cloudflare D1 + Pages Functions）

## 已就绪的代码（本仓库）
| 路径 | 说明 |
|---|---|
| `db/schema.sql` | D1 建表语句（users / sessions / progress / checkin） |
| `functions/api/_lib.js` | 共享工具（JSON / PIN 哈希 / 会话校验 / 中国日期） |
| `functions/api/auth.js` | 注册 / 登录 / 登出（昵称 + 4 位 PIN） |
| `functions/api/report.js` | 学习进度上报 + 当日签到加分 |
| `functions/api/rank.js` | 排行榜（总榜/周榜/日榜）+ 我的信息（连续签到/名次） |

登录方式：**昵称 + 4 位数字 PIN**（家长代建号，儿童友好，零资质）。微信扫码为二期（需企业主体认证）。

## 部署步骤（约 5 分钟，Cloudflare 控制台操作，无需命令行）

### 第 1 步：创建 D1 数据库
1. 登录 dash.cloudflare.com → 左侧「Workers 与 Pages」→「D1」→「创建数据库」
2. 名称填 `huo-yan-d1`（或任意），区域默认，点击「创建」
3. 创建后进入该库 →「控制台」标签（或本页下方 SQL 编辑区）

### 第 2 步：建表
把 `db/schema.sql` 的全部内容粘贴进 D1 控制台的 SQL 编辑器，点「执行」（会依次创建 4 张表）。
验证：执行 `SELECT name FROM sqlite_master WHERE type='table';` 应看到 users / sessions / progress / checkin。

### 第 3 步：绑定到 Pages 项目
1. 左侧「Workers 与 Pages」→ 选择 `huo-yan-personal-site` 项目
2. 顶部「设置」→「函数」→「D1 数据库绑定」→「添加绑定」
3. 变量名称填 **`DB`**（必须与代码一致），数据库选择刚创建的 `huo-yan-d1` → 保存
4. 绑定后需**重新部署一次**才生效（见第 4 步）

### 第 4 步：提交 functions 代码触发部署
后端代码确认无误后，把 `functions/` 和 `db/schema.sql` 提交并推送（Cloudflare Pages 检测到 `functions/` 会自动部署 API，无构建步骤）。若已推送，可在项目「部署」页点「重试部署」触发一次。

### 第 5 步：验证 API
部署完成后（约 1-2 分钟），浏览器访问：
- `https://huo-yan.cn/api/rank?type=total` → 应返回 `{"type":"total","list":[],"me":null}`（空排行榜正常）
- 用 curl 测试注册：`curl -X POST https://huo-yan.cn/api/auth -H 'Content-Type: application/json' -d '{"action":"register","name":"测试宝宝","pin":"1234"}'` → 返回 `{"token":"...","user":{...}}`

## 注意事项
- **时区**：签到按中国日期，由前端传 `date` 参数（D1 的 `date('now')` 是 UTC，直接用于"今天"会差一天）。
- **安全**：PIN 只存 SHA-256 哈希，不存明文；token 随机生成存 sessions 表。
- **免费额度**：Workers 10 万请求/天 + D1 5GB，个人小站用不到 1%。
- **前端改造**（下一步）：登录页、排行榜 Tab、学习进度防抖上报、登录后把本地进度全量同步一次。等 D1 绑定就绪后我继续做前端联调。

## 常见问题
| 问题 | 处理 |
|---|---|
| API 返回 500 / binding 报错 | 检查第 3 步变量名是否为 `DB`，且绑定后重新部署过 |
| 注册提示昵称已占用 | 昵称全局唯一，换一个或直接登录 |
| 排行榜为空 | 正常，有用户学习并上报后才上榜 |
