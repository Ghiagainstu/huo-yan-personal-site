# 盲盒宠物系统 · 设计方案 + 出图 Prompt（2026-08-19 v2）

> 定位：儿童英语学园激励体系第二层。不用积分抽奖（积分留给商城），用「学习成果」换抽取次数——学会新词、游戏连对，都能攒抽奖机会。
> **v2 变更（火哥拍板）**：① 去掉保底机制；② 8 个宠物统一为「火火」本体换装扮（仿 WorkBuddy 一只猫换皮肤的收集模式），形象只此一只、靠装扮区分稀有度。

---

## 一、抽取规则（建议，待火哥拍板）

### 1. 怎么攒抽奖次数（免费、靠学习）
| 行为 | 获得 |
|---|---|
| 每新掌握 **10 个单词**（level 0→3，计入每日新词） | +1 次抽奖机会 |
| 小游戏单局 **连对 10 题**（连击 ≥10） | +1 次抽奖机会 |
| 单局游戏累计答对 **20 题** | +1 次抽奖机会 |

- 抽奖机会 =「盲盒券」，可在盲盒页查看余额（本地 localStorage + 登录后上云，与积分同规则）。
- 机会只增不减，当天没用完可攒着（配合每日 1 次上限，形成长期留存）。

### 2. 抽取节奏（防沉迷 + 可持续）
- **每日抽取上限 1 次**：每天最多抽 1 次，防孩子上头、也给「明天再来」的期待。
- **❌ 无保底**（火哥明确不要）：不设任何"必出"机制。
- **正反馈兜底替代保底**：奖池里积分档合计 **40%**（抽到不亏），用高概率积分小奖保证非酋也有获得感。
- **重复装扮自动折算积分**：抽到已拥有的装扮 → 按稀有度折算积分入账（普通 +5 / 稀有 +15 / 很稀有 +40 / 非常稀有 +100），并提示「已拥有，折成积分啦」。

### 3. 奖池与概率（建议值，v2）
奖池 10 格 = 8 个火火装扮 + 2 积分档，权重总和 100：

| 稀有度 | 装扮 | 单格概率 | 合计 |
|---|---|---|---|
| 🟢 普通 Common ×5 | 原版 / 我的世界像素风 / 变形金刚金属风 / 虎鲸风 / 小猪佩奇风 | 10% ×5 | 50% |
| 🔵 稀有 Rare ×1 | 宇航员风 | 6% | 6% |
| 🟣 很稀有 Very Rare ×1 | 彩虹独角兽风 | 3% | 3% |
| 🟡 非常稀有 Legendary ×1 | 金色传说风 | 1% | 1% |
| 💰 积分小奖 | +10 分 | 30% | 30% |
| 💰 积分大奖 | +50 分 | 10% | 10% |
| **合计** | | | **100%** |

> 概率思路：普通 5 款合计 50%（前中期收集感强、进度快）；高阶 3 款合计 10%（惊喜感）；积分档 40%（抽到不亏的正反馈，替代保底兜底非酋）。
> 可调：若想让「变形金刚金属风 / 虎鲸风」更有价值，可上调到稀有档（普通变 3 款，稀有变 3 款），一句话即可改。

### 4. 前端展示方案
- 「我的中心」新增 **🎁 宠物图鉴**：8 格，已拥有彩色显示、未拥有剪影置灰；点击可「设为展示宠物」。
- 选中宠物显示在**头像下方**（小挂件）或**排行榜头像旁边**，拥有即可炫耀。
- 盲盒入口放商城 Tab：「🎁 盲盒 · 今日 0/1」。
- 出图路径建议：`english-wonderland/images/pet-<slug>.webp`（384×384，与单词图一致），前端用 `PET_IMG` 集合。
- 8 款共用同一形象 → 图鉴里做「换装」展示，抽到新装扮即解锁该外观。

## 二、8 个火火装扮出图 Prompt

### 统一规范（火火本体设定，全 8 款必须一致）
- **火火本体**（每款 prompt 的主干，只改装扮描述）：绿色小恐龙，Q 版圆润；**草绿色皮肤 / 浅绿色肚皮 / 深绿色背棘**；黑亮大眼、粉红腮红；系一条红围巾；橙色三趾脚；粗描边（深棕黑、线宽一致、圆角收尾）。
- **ANCHOR**：儿童教育类扁平卡通插画（Q 版可爱风）：圆润卡通造型，平涂糖果系高明度配色，深棕黑色均匀描边（线宽一致、圆角收尾），极轻顶部高光，主体正面或微侧 3/4 视角，简洁无多余细节。
- **TAIL**：主体居中完整不裁切，占画面约 75%；无文字、无水印、无签名、无 logo、无平台标记；正方形构图，输出 1:1、1K（1024×1024），高分辨率 PNG，纯白背景（#FFFFFF 均匀实色、无渐变、无纹理、无阴影、无地面投影、主体之外全部为纯白像素），便于后期自动抠图。
- **NEGATIVE**：写实照片, 3D渲染, 暗黑风格, 复杂纹理, 花纹背景, 渐变背景, 文字, 水印, 签名, logo, 平台标记, 低幼简笔画, 畸形, 多主体, 模糊, 阴影, 地面投影, 杂乱场景, 多色背景, busy background, gradient, colored backdrop
- 输出 `pet-<slug>.png` → scipy 抠图 → 384×384 webp。
