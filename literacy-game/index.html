字精灵
本应用使用的汉字笔顺数据来自 Make Me a Hanzi 与 Hanzi Writer，原始字体由文鼎科技（Arphic Technology Co., Ltd.）以 Arphic Public License 开源发布。字体：霞鹜文楷（OFL）、站酷快乐体。

关于这个原型

这是面向 5 岁儿童的识字游戏 Web(HTML5) 垂直切片原型，用于验证「认字 → 描红 → 结算 → 节奏 → 存档」核心循环是否好玩。

笔迹中位线数据（Arphic Public License）与字源表均直接复用已有资产；判定/节奏算法严格对齐 GDD。字精灵与真人发音为占位，Sprint 02 接入。

平台：Web / 双击 index.html 即玩（零安装，file:// 可直接运行）。
