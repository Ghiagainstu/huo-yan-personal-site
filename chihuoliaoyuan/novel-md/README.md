# 《赤火燎原》小说源稿（Markdown）

本目录存放《赤火燎原》的 **Markdown 源稿**，网页版（HTML）见 `chihuoliaoyuan/` 上级目录。

- `第01章 ~ 第11章`：第一卷《灶火》（11 章，约 3.2 万字）
- `00_创作大纲与设定.md`：五卷 60 章总纲、赤火九转体系、先祖记忆碎片 7 块设计
- `附录_历史考据与虚构对照表.md`：真实历史（火氏族源 / 下沙盐场 / 黄道婆 / 蒲氏海商 / 百曲地理）与虚构的对照
- `小说简介_网站版.md` / `人物图鉴_网站版.md`：网站展示物料

**写作纪律**：真实历史人物的年代与结局不虚构，只虚构"火家与他们的交集"；直脱儿生平八节点一字不改。
**地理锚点**：百曲位于今浦东新区康桥镇最西端（与闵行浦江镇交界），勿误用"金汇镇"。
